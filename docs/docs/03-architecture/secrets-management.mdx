# Secrets Management

All Kubernetes `Secret` manifests in this repository are encrypted at rest using [SOPS](https://github.com/getsops/sops) with an [age](https://age-encryption.org/) key. This allows secrets to be safely committed to Git alongside the rest of the configuration.

## How It Works

1. **Public key** — The age public key is embedded in `.sops.yaml` files throughout the repository, defining which files are encrypted and which fields are encrypted.
2. **Private key** — The age private key is deployed to the cluster manually as a Kubernetes Secret named `sops-age` in the `flux-system` namespace.
3. **Flux decryption** — Flux Kustomizations have `decryption.provider: sops` and reference the `sops-age` secret. Flux decrypts the encrypted fields automatically during reconciliation.


:::tip[External Reference]

For a step-by-step guide on encrypting secrets with SOPS and age, see this gist: [Encrypting secrets with SOPS and age](https://gist.github.com/Ak0p/7237346590a61652afd084272f36408c)

:::

## Encrypted Files

Files with SOPS-encrypted content include:

- `secrets/base/domain-creds-secret.yml` — Domain name, Cloudflare API token, and other credentials
- `infrastructure/base/pocket-id/release.yml` — Pocket-ID encryption key
- `infrastructure/base/external-dns/adguard-configuration-secret.yml` — AdGuard Home API credentials
- `infrastructure/base/velero/s3-creds-secret.yml` — S3 backup storage credentials
- `apps/base/monitoring/grafana-admin-credentials-secret.yml` — Grafana admin credentials
- `apps/base/radicale/release.yml` — Radicale user passwords (values are encrypted)

## SOPS Configuration

Each encrypted file has a `sops` metadata section at the bottom that includes:

- The age recipient public key
- The encrypted data key
- A MAC for integrity verification
- The `encrypted_regex` pattern (e.g., `^(data|stringData)$` or `^(data|stringData|encryptionKey)$`)

## Deploying the Private Key

The age private key must be deployed to the cluster **before** Flux bootstrapping:

```bash
kubectl create namespace flux-system
kubectl create secret generic sops-age \
  --namespace flux-system \
  --from-file=age.agekey=/path/to/private/key
```

The key is **not** stored in this repository. It is distributed out-of-band.

## Security Considerations

- The private key is never committed to Git
- All Secrets are encrypted at rest in the repository
- Flux decrypts in-memory during reconciliation — the plaintext Secret is never written to disk by Flux
- Access to the Git repository alone is not sufficient to read the secrets
